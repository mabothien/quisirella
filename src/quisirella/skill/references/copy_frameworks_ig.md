# Copy Frameworks — Instagram (Quisirella)

6 khung copy ap dung cho **IG ads** (CTA DM) va **IG organic** (giong than thien, chuyen nghiep, khong phien dien). Nguon: claude-ads `copy-frameworks.md`.

Policy: `output/00-meta-ad-policy-ig.md` (ads) · Organic rule: `quisirella-ig-organic-copy.mdc`

---

## Bang chon khung

| Khung | Buoc | Tot cho | Nhiet do audience |
|---|---|---|---|
| **AIDA** | Attention → Interest → Desire → Action | Cold, launch SKU moi | Cold |
| **PAS** | Problem → Agitate → Solution | Pain (tim mau hiem, qua tang) | Warm |
| **BAB** | Before → After → Bridge | Transformation (style, qua tang) | Warm |
| **4P** | Promise → Picture → Proof → Push | High-ticket, trust-heavy | Hot |
| **FAB** | Features → Advantages → Benefits | Chi tiet chat lieu, macro | Hot / search intent |
| **Star-Story-Solution** | Nhan vat → Cau chuyen → Giai phap | Brand storytelling, UGC feel | Cold-Warm |

**Mac dinh Quisirella:** PAS hoac 4P cho pre-owned luxury (trust truoc); Star-Story cho Reels organic.

---

## Gioi Quisirella (bat buoc)

- Xung "ban"; shop = "Quisirella" hoac "minh" (nhat quan)
- CTA mem: "inbox Quisirella xem them anh / video 360°" — khong "MUA NGAY"
- Trust truoc gia: macro, authentic, nguon Nhật truoc khi nhac so tien
- Phu nu **va** nam (qua tang) — khong stereotype
- Tranh: fake/replica, "cac nang", "gia soc", FOMO toxic

## Template theo khung (IG)

### AIDA (caption ngan, Reels hook)

```
[Hook visual/macro] → [Chi tiet line/chat lieu] → [Cam giac so huu curated] → [CTA inbox]
```

Vi du ads: "Tiffany Return to Tiffany — silver 925, macro tem ro. Mẫu duy nhất tại Quisirella. Inbox xem video 360° nhé."

### PAS

```
[Van de: kho tim authentic / muon qua y nghia] → [Hau qua neu khong co nguon tin cay] → [Quisirella + SKU]
```

### BAB

```
[Truoc: muon luxury nhung lo hang] → [Sau: yen tam voi macro + 1-cua-1] → [Cau noi: Quisirella curated]
```

### 4P (high-ticket)

```
[Promise: authentic pre-owned] → [Picture: deo mang / tang] → [Proof: macro, nguon] → [Push mem: inbox giu mau]
```

### FAB

```
[Feature: chat lieu, size] → [Advantage: so voi hang moi] → [Benefit: gia tri lau dai / qua tang] → [CTA]
```

### Star-Story-Solution

```
[Nhan vat relatable] → [Cau chuyen ngan: tim món cho dip X] → [Quisirella giup chon + xac thuc]
```
